# StikerDead

Teclado Android enfocado en stickers.

## Objetivo

Crear un teclado Android que permita acceder a una biblioteca propia de stickers desde una sección dedicada, similar a la sección de emojis de un teclado convencional.

## MVP

- IME (Input Method Editor) para Android.
- Interfaz simple.
- Biblioteca de stickers.
- Envío de contenido mediante InputConnection cuando la aplicación receptora lo soporte.
- Base preparada para agregar categorías, favoritos, búsqueda y paquetes de stickers.

## Desarrollo

El proyecto se desarrolla localmente y se sincroniza con GitHub.
